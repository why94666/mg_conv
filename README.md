# 小鸡转换器

网易云音乐 NCM 批量转换与音频标签清理工具。本仓库包含 Windows 桌面版和纯前端 Web 版。

> 桌面版当前为 **MP3 输出版 v6.2.1**：NCM 解密后不再产出 FLAC，并会自动修复“伪装成 .mp3”的 M4A/AAC 文件。
>
> Web 版位于 [`web/`](web/)，在浏览器内完成 NCM 解密、标签清理和 MP3 转换，适配手机与桌面。

## 功能

- 网易云 `.ncm` 解密转换（纯 Python 实现，不依赖外部 ncmdump.exe）
- 自动检测并转换“扩展名是 .mp3、实际不是 MP3”的文件
- 标签清理：仅人物信息 / 人物 + 专辑 / 全部清空
- 按标题批量重命名
- 抖音分享链接音频导入
- 上传适配：转 MP3、控制在 20MB 内、按平台规则命名
- 歌词下载（.lrc）

## 本版改动

### 2026-11-12：伪装 MP3 自动修复

1. **自动识别伪装的 .mp3**：扩展名是 `.mp3`，但文件头实际是 M4A/AAC、FLAC 等格式时，一键处理会自动转成真正的 MP3（最高 192k），并给出提示。
2. **添加文件时提示**：加入这类文件时，日志会提示“实际不是 MP3，处理时会自动转为真 MP3”。
3. **只读文件兼容**：微信/下载得到的只读文件，覆盖前会自动清除只读属性；无法覆盖时生成 `*_mp3.mp3` 备用文件。

### 2026-11-06：MP3 输出版

1. **取消 FLAC 输出**：NCM 解密结果如果是 FLAC，会自动使用内置 PyAV / libmp3lame 转成 **320k MP3**，并删除中间产生的 FLAC；界面文案同步改为 `ncm → mp3`。
2. **移除顶部副标题**：去掉 `NCM 解密 · 标签清理 · 抖音导入 · 平台适配（内置运行环境，免安装）`。
3. 原有清标签、重命名、链接导入、上传适配等功能保留。

对已有 `.flac` 文件做清标签、改名仍然可用，程序不会主动删除非 NCM 产生的 FLAC；只有 NCM 解密产生的 FLAC 会被转码并删除。

## 使用

1. 下载或克隆本仓库。
2. 双击 `小鸡转换器.exe`（Windows 10/11 64 位）。
3. 把 `.ncm` 文件或文件夹拖进窗口，选择处理内容和输出位置。
4. 点击「一键处理」。

程序内置运行环境，无需安装 Python 或 FFmpeg。

> 如果输出目录里已有旧版生成的同名 `.flac`，默认的「同名策略：跳过」会跳过该文件。请先删除旧 `.flac`，或把同名策略改为「覆盖」后再处理。

## Web 版

`web/` 是纯前端版本，不需要安装客户端：

- NCM 解密、标签清理、FLAC/MP3/M4A/AAC/OGG/WAV 转 MP3
- 文件只在浏览器本地处理，不上传服务器
- 响应式布局，手机和桌面都能用
- 支持批量处理和 ZIP 打包下载

本地开发：

```bash
cd web
npm install
npm run dev
```

构建静态站点：

```bash
cd web
npm run build
```

部署到 EdgeOne Pages：项目根目录填 `web`，构建命令 `npm ci && npm run build`，输出目录 `dist`。详细说明见 [`web/README.md`](web/README.md)。
